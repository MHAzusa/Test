# 計算ゲーム

## 概要

計算問題を解いて遊ぶゲームです。

個人学習を目的として開発しています。

本プロジェクトでは、ゲームそのものの開発だけでなく、
要件定義、設計、データベース設計、実装、テストなど、
ソフトウェア開発の一連の工程を学習することも目的としています。


## 目的

- 計算問題をゲーム形式で解く
- プログラミングの学習
- ソフトウェア開発工程の学習
- 要件定義・設計・実装・テストの経験
- Git / GitHubを利用した開発経験


## 開発状況

現在は要件・仕様を検討中です。


## ドキュメント

| ドキュメント | 内容 |
|---|---|
| [要件定義](docs/requirements.md) | システムが満たすべき要件 |

| [仕様決定ログ](docs/decisions.md) | 仕様を決定した内容と理由 |
| [レビュー履歴](docs/review.md) | AIによるレビュー結果 |


## 開発方針

このプロジェクトは個人学習を目的としています。

そのため、必要以上に複雑な設計を避け、
現在の学習目的とシステム規模に適した構成を目指します。
